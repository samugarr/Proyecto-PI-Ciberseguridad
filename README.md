# Proyecto Protección de la Información

Requisito: tener instalado Node y npm.

Certificado (solo la primera vez, desde la carpeta raíz):
npm install
npm run certs
npm run trust-cert

Levantar servidor (desde la carpeta raíz):
npm run build
npm start

Levantar cliente (en otra terminal):
cd client
npm install
npm start

La web funciona en https://localhost:4200
